RaceTwin AI v0.1 — Offline Windows Prototype

HOW TO START
1. Extract the complete ZIP archive.
2. Double-click START_RACETWIN.cmd (or open RaceTwin_AI.html).
3. Choose an included Keeneland race or click OPEN BRISNET .DRF.
4. RUN RACE animates a synthetic race; RUN 10,000 SIMULATIONS
   summarizes synthetic winner and exacta frequencies.
5. Pace pressure and randomness controls change the scenario.

No installation, internet, Python or administrator privileges required.
Runs in a modern browser on Windows.

IMPORTANT MODEL LIMITATIONS
This prototype uses normalized morning-line odds as its baseline.
It does not decode historical BRIS Speed, E1, E2 or Late Pace.
Pace dynamics are illustrative, not validated physical predictions.
The simulation is not suitable for real-money betting decisions.
The provided cards are from 2026-10-09 and 2026-10-14.
Official results are not used for training or validation.

Next development: verified BRIS field map, pace simulation calibrated
against historical calls and finish orders, and out-of-sample testing.
